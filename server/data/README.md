# Seed data

`owner_synthetic_v3.json` is a normalized, application-ready copy of the
owner-provided workbook `Asset_Passport_Synthetic_Test_Data hb v3 Emailed.xlsx`.
It contains fictional development records only. The source workbook remains
outside the repository and is never modified by the extraction process.

Troubleshooting entries remain synthetic and unverified because the workbook's
`Verified By` and `Review Date` fields are blank. The application must not
present them as production-approved procedures or real repair outcomes.
