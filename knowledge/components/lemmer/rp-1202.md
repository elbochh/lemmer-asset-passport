# RP-1202 / RP-1202N component reference
Source: https://lemmer.com/wp-content/uploads/2026/01/part-diagram-RP-1202.pdf
Revision: undated supplied sheet; includes 2018 and 2024 variant notes.
Review: listed rows visually checked against diagram, September 2026.

The lower packing changed in 2018; the new 10 mm packing requires two 8.4 mm glands for the documented upgrade. The upper packing and pump base differ before/after 2024. Match the actual pump version before selecting parts. This is not an instruction to modify a pump. Selected identified rows are listed; no lifetime or current stock is established.
