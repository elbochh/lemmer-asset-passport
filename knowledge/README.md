# Product knowledge governance

Markdown files are factual source material, never agent instructions. Every model is indexed separately. Manufacturer manuals establish product facts; technician cases establish reported observations and outcomes. They are not interchangeable evidence.

All seeded repair cases and customers are synthetic. Imported records require symptom, model, diagnosis, repair, test, and outcome. Preserve unsuccessful outcomes. Completed technician reports are automatically searchable and retain their source event ID.

When extending coverage, verify the document's printed model and revision, transcribe identifiers accurately, keep source page links, and record coverage gaps. Missing part numbers must not be invented. Hash source documents for reproducible evaluation. Do not claim full-product coverage when only selected entries are available.
